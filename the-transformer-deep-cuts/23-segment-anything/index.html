Segment Anything: Promptable Visual Segmentation

How Segment Anything Model (SAM), introduced by Kirillov et al. (Meta), turns images into masks under user control—like prompting in language modeling, but for pixels. Encoder–decoder design, MAE-pretrained ViT, ambiguity-aware multi-mask outputs, and the SA-1B data engine.

00 — Overview

What is image segmentation?

Image segmentation partitions a digital image into regions so pixels in the same region share coherent properties. Classic pipelines were application-specific: medical cell boundaries, pedestrians for autonomy, land cover in satellite imagery. Each domain needed costly pixel-level labels and its own specialized model.

Before promptable models, segmentation required pixel-by-pixel labels per application—medical, autonomy, satellite—and a separate model per domain. You could not ask for “all cats” or “all trees” unless that category was baked into training.

Segment Anything targets open-world images: one model produces masks for diverse scenes without retraining per category. Its second breakthrough is promptable segmentation: you steer the output with points (foreground / background clicks), axis-aligned boxes, text (via a text encoder), or combinations—for example a box plus corrective points.

In an interactive UI, foreground clicks include regions and background clicks exclude them; a box localizes a target, and extra points refine the result. The image encoder runs once per image; only the prompt encoder and mask decoder rerun on each edit—typically on the order of 50 ms per mask in web deployments.

Ambiguity is real. A single click on produce might mean this vegetable only, the whole group of vegetables, or just the pale interior of one piece—humans disagree too. On text, a click on the letter Z might refer to the glyph, the entire line of text, or the wall behind it. The model cannot read intent; it must return at least one reasonable mask for the click, and ideally surface multiple interpretations.

01 — Vision foundation models

From task-specific models to foundation models

A foundation model is trained at scale on broad data, then adapted through prompts or light fine-tuning rather than rebuilding per task. SAM applies the same pattern to visual prompting: given points, a box, text, or a mix, produce a mask consistent with that prompt—not only “find class k.”

That shift matters because dense segmentation labels are expensive: human annotators trace boundaries pixel-wise. SAM’s design couples a heavy, run-once image encoder with a fast prompt encoder and mask decoder so the UI can refresh masks quickly after each edit—image embeddings are cached while prompts change. Only the prompt encoder and mask decoder rerun when you add clicks or resize a box; the ViT forward pass on the image is amortized across many prompt edits.

The training story mirrors the architecture’s ambition: the team started from a small labeled set, trained a model, used that model (with humans in the loop) to produce a larger set, and eventually scaled to fully automatic mask generation before training the final system on about 1.1 billion masks—so the dataset and the model co-evolved.

02 — Three design pillars

Task, model, and ambiguity awareness

The SAM paper highlights three innovations working together:

  • Promptable segmentation task. Unified interface for points, boxes, text, prior masks, and mixtures.
  • Efficient encoder–decoder stack. Strong image representation (ViT-H image encoder) plus lightweight prompt encoding and a two-layer mask decoder suitable for interactive latency.
  • Ambiguity handling. For an under-specified prompt (often a single point), output up to three ranked masks; with multiple prompts, a fourth mask token can be used internally—outputs collapse toward a single refined mask when ambiguity drops.

The three-mask design matches how ambiguity shows up in practice: ranked hypotheses often correspond to a part, a sub-part, and the whole—three legitimate segmentations of the same click (equivalently: a tight region, a finer fragment, and an expanded context). When you supply more than one prompt, ambiguity drops, so the stack can route a fourth output token to an extra mask head; that fourth path is for the multi-prompt regime and is not surfaced for a lone single-point prompt.

03 — SAM architecture

Image encoder, prompt encoder, mask decoder

End-to-end, SAM is an encoder–decoder:

  • Image encoder maps the input image to a dense embedding grid (MAE-pretrained Vision Transformer backbone).
  • Prompt encoder embeds sparse prompts (points, boxes, text) into the same channel width as image features (256 dimensions) so they can fuse in attention.
  • Dense prompt (optional): a previous mask is downsampled through convolutions and added element-wise to image embeddings—supplying a “hint” for iterative refinement.
  • Mask decoder consumes (image features + mask hint) and prompt tokens; it predicts binary masks and IoU quality scores for each hypothesis.

End-to-end, the decoder’s job is to emit a mask together with a confidence-style score (implemented via IoU prediction) so that, at inference time, multiple hypotheses can be ranked without access to ground-truth labels.

Iterative refinement. Run the model once with an initial prompt (e.g. one point) to get a first mask. If you then add points instead of starting cold, you can feed that previous mask back as a dense prompt: it tells the network “this was close—adjust with these additions or subtractions.” The mask is not a new modality for its own sake; it is the last prediction recycled as a geometric hint.

04 — Image encoder (ViT + MAE)

Patch tokens, MAE pre-training, salient features

The Vision Transformer (ViT) treats an image as a token sequence. Following the line of work summarized in An Image is Worth 16×16 Words (Google Research), the image is divided into fixed-size patches—16×16 pixels in the canonical setup—each patch is flattened and linearly projected into an embedding that summarizes local appearance. Those patch embeddings, plus positional encodings, feed a Transformer encoder whose self-attention lets every patch attend to every other patch, building context across the whole field of view.

For image classification, ViT prepends a learnable class token (the same “special token” idea as in BERT). Self-attention mixes that token with all patches; after the stack, the first output position—the class token’s final state—is passed through an MLP head to predict the label. Intuition: because the class token attends to every patch, the training objective forces it to compress global information from the entire image into one vector.

SAM’s image encoder builds on a Masked Autoencoder (MAE) recipe from Masked Autoencoders Are Scalable Vision Learners (Meta): roughly 75% of patches are masked (removed or zeroed); the encoder runs only on the visible (~25%) patches. The encoder output is then arranged back into the original patch grid—with placeholders for masked slots—and a decoder attempts to reconstruct the full image. Training asks: can you recover the hidden pixels knowing only the visible quarter? When the answer is “reasonably yes,” the encoder’s hidden states must encode most salient information about the scene in a compact representation—exactly what you want before a segmentation head.

MAE pretraining gives a generic visual prior—structure, texture, layout—not just boundary cues—before segmentation fine-tuning. SAM keeps the MAE-pretrained ViT encoder (ViT-H scale) and discards the MAE decoder; the encoder feature map is what the mask decoder cross-attends to.

05 — Prompt encoder

Sparse vs dense prompts and 2D positional encoding

Sparse prompts include point clicks, two corners of a box, and text. Each point has coordinates (x, y) and a label: foreground (add to mask) or background (subtract). Embeddings are built as positional encoding(point) + type embedding—separate vectors for foreground, background, top-left box corner, bottom-right, padding, etc.—all mapped to 256 dimensions to match image features.

Implementation-wise, points arrive as a sequence of (x, y) pairs and label indices: foreground points add one learned vector, background points add another, and padding positions (when the batch packs variable-length prompts) use a dedicated padding embedding so the Transformer sees a fixed-width sequence. Boxes are two corners—top-left and bottom-right—each gets the same positional-encoding machinery as a point, then corner-specific type embeddings distinguish “this xy is upper-left” from “this xy is lower-right.”

Text uses the text tower from CLIP: a sentence becomes a fixed-width embedding aligned with the image–text contrastive space, then projected into the fusion width.

For dense prompts, an input mask (often the previous prediction) is conv-downsampled to the image embedding resolution. If no mask is provided, a learned “no mask” embedding is broadcast. Fusion with the image map is a point-wise sum.

In the original Transformer (Attention Is All You Need), positional encodings combine sines and cosines of different frequencies so each token index maps to a unique vector; that works when position is one-dimensional (token 0, 1, 2, … along a sentence). Images are not 1-D: pixels vary along height and width simultaneously.

Unlike 1-D sinusoidal positions along a sentence, images need 2D locality: Euclidean neighbors should be represented similarly. Independently encoding x and y with separate 1-D sinusoids can break isotropy—two pixels at similar image distance may look unrelated in embedding space. SAM adopts a Fourier feature positional encoding suited to continuous 2-D coordinates (as analyzed in Fourier-feature positional encoding work referenced alongside SAM).

Separable x and y encodings

If you encode horizontal and vertical coordinates with independent sinusoidal tables (as in the original Transformer for token index), a reference pixel can appear very similar to another pixel along a row or column yet dissimilar to a third pixel that is actually the same Euclidean distance away along a diagonal. That breaks the geometry images live in.

Distance-aware (Fourier-style) encoding

What you want instead: fix an anchor; all pixels within a small radius (say 10 px) should have high similarity; pixels near 20 px should be less similar but still structured; similarity should depend on radius the same way in every direction, then fall off smoothly as you move outward—so local neighborhoods stay coherent in embedding space.

Learnable Fourier features for multi-dimensional coordinates appear in the literature as one principled fix; SAM’s implementation follows the paper’s chosen Fourier-feature recipe rather than naive separable axes. The shared width—256 channels for prompts and for the image map—is what allows attention to fuse the two streams without an extra projection bottleneck at every interaction.

When reading the official code, every sparse location still lands in the same 256-D fusion space; occasional commentary may typo “266,” but the tensor width matches the image embedding channel count.

06 — Mask decoder & ambiguity

Attention flow, output tokens, multi-mask heads

The mask decoder stacks two identical transformer blocks. Each block performs:

  1. Self-attention on prompt tokens and special output tokens (concatenated sequence).
  2. Cross-attention where queries are tokens and keys/values are image embeddings (prompt looks at the image).
  3. A feed-forward MLP.
  4. A second cross-attention with roles swapped: queries are image locations, keys/values are tokens (image looks back at the prompt).

Output tokens mirror BERT’s class token: learned slots prepended to the prompt sequence pool context via self-attention. SAM uses one IoU token (fed to an MLP that predicts intersection-over-union quality) and three mask tokens that, with upsampled image features, generate three low-resolution masks upscaled to full resolution.

Positional encodings are re-added to image and prompt streams whenever they enter attention so geometric cues are not washed out—akin to residual positional refresh without duplicating the entire skip path.

Kirillov et al. emphasize that geometric information must not dissipate across depth: positional encodings are added back to image embeddings and to prompt embeddings whenever those tensors participate in attention, much like repeatedly nudging residual streams so locality survives many blocks.

Because the decoder stacks two identical transformer blocks, the pattern repeats: block one’s outputs feed block two. After both blocks, the pathway splits. One stream is the updated tokens (output slots + prompts); the other is the updated image feature map (src in the reference implementation). The IoU token is read first and passed through a small head to predict how well each mask will overlap ground truth at train time. Each mask token is sent through its own MLP; those vectors are combined with an upsampled copy of the image embedding to synthesize three low-resolution masks that are then upscaled to full image resolution.

The dual cross-attention pattern mirrors encoder–decoder Transformers for translation: first, queries = tokens, keys/values = image lets the prompt “look at” the scene; second, queries = image, keys/values = tokens lets each spatial location absorb what the prompt requested. You need both directions because one output sequence must carry mask-specific semantics (the output tokens) while the other must carry spatially aligned features for mask synthesis.

Latency budget. The image encoder may be large and relatively slow; that is acceptable because each image is encoded once and the embedding is cached. What must stay fast for interactive use is the prompt encoder and the two-layer mask decoder—those rerun on every edit so the UI can feel instantaneous (on the order of tens of milliseconds on capable hardware).

07 — Training, SA-1B, and losses

Data engine, automatic labeling, and supervision signals

SA-1B contains on the order of 11 million images and 1.1 billion masks. Building it relied on a three-stage data engine that escalates from pure human labor to model-assisted curation to fully machine-generated proposals:

Stage A — Assisted manual

A team of professional annotators labeled images using only brush and eraser tools—true pixel-by-pixel painting. This is the expensive baseline: every mask is human-made, comparable to building a segmentation dataset “from zero” without model help.

Stage B — Semi-automatic

Train a model on Stage A, then let that model propose masks. Human operators correct proposals and annotate objects the model missed. Throughput rises because humans edit rather than draw every mask from scratch; the expanded corpus retrains the model again.

Stage C — Fully automatic

No human in the loop. For each image, place a regular grid of 32 × 32 point prompts (1024 seeds). The model emits candidate masks for every seed. Retain masks that combine high predicted IoU (model-estimated quality) with stability: threshold the probability map at 0.5 − δ and 0.5 + δ; if the resulting binary masks stay nearly the same, the proposal is stable under jitter. Because thousands of seeds yield massive overlap and duplicates, run non-maximum suppression (NMS).

NMS in one pass. Sort mask proposals by confidence. Take the top mask, then discard every remaining mask whose IoU with the chosen mask exceeds a fixed threshold. Repeat with the next surviving highest score. The same greedy filter used in object detection to collapse duplicate boxes applies here to collapse duplicate segments.

Mask loss blends focal loss (handles extreme foreground/background pixel imbalance compared to plain cross-entropy) and Dice loss derived from the Dice coefficient (related to F1 overlap). SAM uses a high ratio of focal to Dice—on the order of 20 : 1—so hard pixels and class imbalance dominate while overlap geometry is still explicitly shaped.

Focal loss (×20)

Generalizes cross-entropy with a focusing term that down-weights easy negatives. Dominates when the mask covers only a tiny fraction of pixels so the model still spends capacity on hard boundaries and rare foreground.

Dice loss (×1)

Directly penalizes mismatch in set overlap between prediction and target. Weaker weighting leaves geometry refinement to a secondary channel while focal handles class imbalance.

IoU = |A ∩ B| / |A ∪ B|  Dice = 2|A ∩ B| / (|A| + |B|)  Ldice = 1 − Dice

IoU (Jaccard index) measures overlap between a prediction and the ground-truth region: perfect coverage of the true object with no spill yields IoU → 1; a shifted or shrunk box shares some intersection but also extra union mass, so the score stays middling until alignment tightens. In detection-style diagrams, false positives are predicted area outside the ground truth; false negatives are ground-truth area the model missed. Segmentation inherits the same vocabulary at the pixel level.

The IoU prediction head is trained to regress agreement between each predicted mask and the ground-truth mask so inference can rank multiple outputs without oracle labels.
